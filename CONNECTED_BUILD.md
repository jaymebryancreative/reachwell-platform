# Reachwell Connected Build

## Current implementation priority

1. People profiles and connected records
2. Custom teams and ministry groups
3. Team channels, announcements, direct and group communication
4. Event rosters, scheduling, attendance and event communication
5. Mission Mode with persistent Note/Need/Prayer records and progress
6. Workspace projects and tasks connected to people, teams and events
7. Settings control center for organization, members, roles, permissions, notifications, security and data
8. Finance and giving workflows with restricted access, reporting and export
9. Data continuity, files, retention and organization export
10. Contextual AI help with permission-aware responses

## Definition of done
A feature is not complete because a page exists. It must have a usable workflow, persistent organization-scoped data, permission-aware access, and connected relationships where applicable.

## Communication model
- Organization announcements
- Team channels
- Event channels
- Project/task discussions
- Direct conversations
- Group conversations
- Search/history/notifications
- Attachments through authorized storage
- Email delivery through a configured provider

## Core relationship model
Person → Teams/Groups → Roles → Events → Serving → Attendance → Communication → Follow-up

Team → Members/Leaders → Channel → Events → Workspace → Mission progress
